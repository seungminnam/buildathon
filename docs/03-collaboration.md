- Ryan은 Claude **Pro**, 팀원은 Claude **Max**를 써요. 계정과 컴퓨터가 따로예요.
- Orca와 Claude Code desktop은 둘 다 로컬에서 돌아가서, 세션이나 대화를 실시간으로 공유하는 기능은 없어요.
- 그래서 **GitHub repo가 유일한 공유 통로**이고, 맥락은 **repo 안의 파일로** 공유해요.

## 맥락을 공유하는 파일

| 파일 | 내용 | 언제 업데이트 |
|---|---|---|
| `CLAUDE.md` | 프로젝트 규칙, 실행과 채점 방법. 두 사람의 Claude가 시작할 때 자동으로 읽어요 | 실행 방법이 바뀔 때 |
| `docs/briefs/` | 공식 문제와 규칙 원문 | 처음 한 번 (공지가 바뀌면 다시) |
| `docs/log.md` | 실험과 제출 기록 | **실험하거나 제출할 때마다** |
| `docs/decisions.md` | 결정과 이유, 버린 접근 | 결정할 때마다 |

규칙은 하나예요: **작업 시작 전에 `git pull`, 끝나면 `log.md` 업데이트하고 commit과 push.**

## 역할 분담

- **Max (팀원):** 오래 혼자 도는 무거운 코딩. 본 알고리즘이나 파이프라인 구현.
- **Pro (Ryan):** 사용량 한도가 작으니 짧고 정확한 작업. 로컬 채점기와 테스트, 리뷰, 결과 분석, **제출 관리**.
- **제출은 한 명이 맡아요.** 제출 한도는 팀 단위예요.
- 맡는 모듈을 나눠서 같은 파일을 동시에 고치지 않게 해요. 브랜치는 짧게 쓰고 main에 자주 합쳐요.
- 실시간 대화는 카톡, Discord, 음성으로 하고, 결론만 `decisions.md`에 한 줄 남겨요.
