## 핵심 규칙

- 심사위원이 없어요. 트랙마다 공개된 채점 규칙과 숨겨진 테스트로 나온 숫자 하나로 순위가 정해져요.
- 상금은 트랙당 $5,000이고 1등만 받아요. 2등은 없어요.
- 참가자 약 1,760명, 팀 922개 (금요일 기준).
- 대부분의 트랙에서 **동점이면 먼저 제출한 팀이 이겨요.** 일찍 좋은 점수를 내는 게 중요해요.
- 제출 한도가 작아요 (시간당 1~4회). 그래서 **로컬 채점기로 실험하고, 서버 제출은 확실히 나아진 것만** 하는 게 기본 전략이에요.
- "public GitHub repo + Dockerfile" 제출이 많아요. 제출한 커밋은 결과 발표 전까지 지우면 안 돼요.

## 문서 구성

- `01-tracks.md`: 4개 트랙 요약, 리더보드 현황, 추천
- `02-plan.md`: 남은 시간 계획
- `03-collaboration.md`: 2인 협업 방식 (Pro + Max, GitHub)
- `log.md`: 실험과 제출 기록 (계속 업데이트)
- `decisions.md`: 결정 기록 (계속 업데이트)
- `briefs/`: 트랙 페이지 원문(.txt)과 공식 규칙 파일(.md, .pdf)
